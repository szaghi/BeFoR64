# About BeFoR64

BeFoR64 is a pure Fortran library that encodes and decodes data conforming to the
[Base64 binary-to-text encoding scheme](http://en.wikipedia.org/wiki/Base64).

Modern Fortran standards (2003+) introduced better support for string manipulation.
BeFoR64 exploits those capabilities to provide an easy-to-use module library for
encoding and decoding Fortran types — in their binary internal representation — as
ASCII Base64 strings.
